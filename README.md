# إدارة العمال

تطبيق Flutter لإدارة بيانات العمال مع إمكانية البحث والمشاركة.

## الميزات

- إضافة وتعديل وحذف بيانات العمال
- البحث بالاسم أو رقم التسجيل أو رقم الهاتف
- عرض إحصائيات (إجمالي، متزوج، أعزب، بهاتف)
- تصدير واستيراد البيانات عبر ملفات JSON
- اتصال هاتفي مباشر
- واجهة مستخدم سلسة باللغة العربية

## التشغيل

1. تأكد من تثبيت Flutter
2. قم بتشغيل `flutter pub get`
3. شغل التطبيق بـ `flutter run`
